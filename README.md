# 🍽️ Zomato Data Analysis

## Project Overview
Analyzed Zomato restaurant data using Python to explore restaurant ratings, votes, costs, restaurant types, and online ordering trends.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Analysis
- Data Cleaning and Preprocessing
- Restaurant Type Analysis
- Customer Votes Analysis
- Rating Distribution
- Online vs Offline Orders
- Data Visualization

## Key Learning
Gained practical experience in data cleaning, exploratory data analysis (EDA), and data visualization using Python.
